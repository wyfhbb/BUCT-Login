# 测试脚本

`go test ./...` 覆盖的是纯逻辑（探测判定、轮询推进、慢通道计时、状态文件、防重叠锁）。
这里的两个脚本跑的是**真实校园网环境**下的端到端行为，需要能登录的账号。

## 用法

```bash
export BUCT_USERNAME=你的学号
export BUCT_PASSWORD=你的密码

./scripts/e2e-test.sh          # 非破坏性，全程保持在线
./scripts/disconnect-test.sh   # ⚠️ 会真的登出，断网数秒
```

凭据只从环境变量读,临时配置写在 `mktemp` 目录里（权限 `0600`），脚本退出时连目录一起删除。
密码不会出现在命令行参数里，所以也不会出现在 `ps` 输出或日志中。

## 两个脚本的分工

| 脚本 | 覆盖的场景 | 会不会断网 |
| --- | --- | --- |
| `e2e-test.sh` | 首次运行建立核对时间、网站池轮询推进、慢通道到期与未到期、防重叠锁、劫持识别 | 否 |
| `disconnect-test.sh` | 错账号检测 → 登出 → 用错账号登录失败 → 探测发现掉线 → 自动重登 | **是** |

## 安全网

`disconnect-test.sh` 会真的让机器掉线，所以：

- 恢复逻辑挂在 `trap` 上，正常结束、报错、`Ctrl-C`、被 `kill` 都会先尝试把账号登回去（重试 3 次）
- 恢复用 `-probe=false` 直接走门户，不依赖公网
- 校园网门户在内网，掉线状态下依然可达，所以恢复始终有路可走
- 运行前有交互式确认，`YES=1` 可跳过

信号处理器是 `restore; exit`，不能只 `restore`——否则脚本会从被打断的位置继续往下跑，而此时临时配置已经被删掉了。

## blackhole 辅助程序

`blackhole/` 是一个只接受 TCP 连接、永远不回数据的小程序，用来把一次运行卡在探测阶段，
好让第二个进程撞上锁。测试防重叠必须有一个「跑得足够久」的进程占住锁，而 connection refused
和不可路由地址都是瞬间返回的，制造不出真实的重叠。
